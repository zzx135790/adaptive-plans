- CLI and MCP return equivalent structured outcomes and never claim that a discovery failure means no provider is installed
- Before implementation, the node is decomposed into a finalise-plan-reviewed leaf plan with exact paths, validation commands, and independent commit boundaries.
- CLI and MCP expose equivalent approval_brief fields, and the terminal flow displays them before requesting approval.
- Terminal output distinguishes discovery, invocation, dependency readiness, persisted output, and fallback instead of collapsing them into available/unavailable.
